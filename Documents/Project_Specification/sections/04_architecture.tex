\chapter{System Architecture}

\section{Architecture Overview}

The system consists of three main components:

\begin{enumerate}
  \item \textbf{Mobile application (React Native)} --- cross-platform client for iOS and Android
  \item \textbf{Backend server (Node.js / Express)} --- REST API + WebSocket server
  \item \textbf{Database (PostgreSQL)} --- persistent data store
\end{enumerate}

Communication flows as follows:
\begin{itemize}
  \item Mobile app $\leftrightarrow$ Backend: \textbf{HTTPS REST API} for standard operations
  \item Mobile app $\leftrightarrow$ Backend: \textbf{WebSocket (WSS)} for real-time chat and location sharing
  \item Backend $\rightarrow$ Mobile app: \textbf{Firebase Cloud Messaging} for push notifications
  \item Mobile app $\leftrightarrow$ Firebase: \textbf{Firebase Analytics + Crashlytics} SDK
\end{itemize}

\section{Backend}

The backend is implemented in \textbf{Node.js} with the \textbf{Express} framework. It runs in a Docker container alongside a PostgreSQL database (docker-compose).

Main backend modules:
\begin{itemize}
  \item \texttt{auth} --- registration, login, Google OAuth, JWT issuance and verification
  \item \texttt{jobs} --- CRUD endpoints for jobs, worker assignment
  \item \texttt{users} --- user and role management
  \item \texttt{media} --- binary content upload and download (photos)
  \item \texttt{socket} --- Socket.IO handlers for chat and location
  \item \texttt{notifications} --- FCM message dispatch
\end{itemize}

Interactive API testing is provided via \textbf{Swagger UI} at \texttt{/api-docs}.

\section{Mobile Application}

The application is built with \textbf{React Native} using a \textbf{Redux Toolkit} architecture:

\begin{itemize}
  \item \texttt{api/} --- axios HTTP client, WebSocket (Socket.IO client)
  \item \texttt{store/} --- Redux slices and async thunks (Redux Toolkit)
  \item \texttt{db/} --- local SQLite database via WatermelonDB
  \item \texttt{screens/} --- React Native screens and navigation (React Navigation)
  \item \texttt{components/} --- shared UI components
\end{itemize}
